# Sources du site lovelydayevent.fr

Lire **CLAUDE.md** : organisation du dépôt, publication (`./publier.sh`), articles programmés et décisions validées.

- `python3 build.py site` régénère toutes les pages dans `site/` (FR + EN).
- `./publier.sh "message"` met le site en ligne (branche `production`, Sevalla) et prépare les parutions programmées.
